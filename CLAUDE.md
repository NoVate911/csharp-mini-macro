# CLAUDE.md — Mini Macro

## О проекте

**Название:** Mini Macro  
**Автор:** NoVate Source  
**Стек:** C# (.NET 10.0), WPF, Visual Studio Community 2026  
**Формат файлов макросов:** `.mmacro` (собственный формат)

---

## Системы

### 1. Запись действий
- Перехват событий клавиатуры и мыши через Windows API (hooks)
- Учёт разрешения экрана пользователя (координаты мыши нормализуются)
- Поддержка модификаторов: Shift, Ctrl, Alt, Win
- Поддержка сочетаний клавиш

### 2. Воспроизведение
- Точное воспроизведение записанных событий с учётом задержек
- Скорость регулируется (до 5x)
- Количество повторов (до 50)

### 3. Сохранение в файл `.mmacro`
- Собственный формат (JSON или бинарный — решить в ходе разработки)
- Расширение `.mmacro`

### 4. Загрузка из файла
- Открытие `.mmacro` из любой папки (стандартный диалог)

### 5. Библиотека макросов
- Пользователь указывает папку; все `.mmacro` из неё отображаются в интерфейсе
- Функции: назначение горячей клавиши, удаление, перезапись, загрузка

### 6. Меню настроек
- Слайдер: количество повторов (1–50)
- Слайдер: скорость воспроизведения (0.5x–5x)
- Кнопка смены папки библиотеки макросов

## Стратегия веток

- **`dev`** — вся активная разработка и тестирование
- **`main`** — только стабильный код для публичных релизов

Коммиты и PR: сначала в `dev`, после проверки — merge в `main`.

---

## Релизы (GitHub Releases)

При публикации релиза:
1. Собрать `.exe` (Release конфигурация, self-contained или framework-dependent — уточнить)
2. Написать описание: что изменено, ссылки на коммиты
3. Описание — на русском, структурированное
